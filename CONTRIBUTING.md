# Contributing to DSH Plugin Recommender

Thanks for your interest in contributing! 🎉

## How to Help

### 🐛 Report a Bug
If you find a miscategorized plugin or broken link:
1. Open an [Issue](https://github.com/tanle-mtr/dsh-plogin-plugin-recommender/issues)
2. Include the plugin name, current category, and suggested category

### ✏️ Fix a Misclassification
Most misclassifications are awesome lists that AI puts in "Other". To fix:
1. Edit `scripts/fix-categories.js` and add your plugin to the corrections map
2. Run `node scripts/fix-categories.js` to test
3. Submit a PR

### ⭐ Star the Repo
The best way to help is to spread the word. If this list saved you time, give it a star!
