## How It Works

1. **Discovery** — Searches GitHub for repos matching `dsh-plugin`, `deepseek-harness`, `awesome-dsh-plugin`, etc.
2. **AI Categorization** — Each plugin is analyzed by AI and assigned to the best-fitting category

4. **Hourly Updates** — GitHub Actions runs every hour to fetch new plugins and regenerate this list
