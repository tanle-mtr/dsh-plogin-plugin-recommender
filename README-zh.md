## 工作原理

1. **发现插件** — 搜索 GitHub 上匹配 `dsh-plugin`、`deepseek-harness`、`awesome-dsh-plugin` 等关键词的仓库
2. **AI 分类** — 每个插件由 AI 分析并分配到最合适的分类
3. **人工校正** — 修正表修复已知错误分类（awesome 列表等）
4. **每小时更新** — GitHub Actions 每小时运行一次，获取新插件并重新生成列表
